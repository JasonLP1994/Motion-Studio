# Phillips Digital ident: plan (v1)

**Brief:** 16:9 1920×1080, 8 s (240 frames, 30 fps), sound design (~-14 LUFS). End words: **PHILLIPS DIGITAL** in a code-style
monospace (Liberation Mono Bold, OFL, slightly condensed): user asked for "Matrix-like font", so take the feel, not the film's logo type. No logo mark.
Colours (phillipsdigital.net): forest-black #0A1C0B / #10251C, deep green #0B241A, lime #C9FA44 / #D7FC70,
cream #F8F8F2 / #FFFDF7, sage #62716A / #C5D4C7. Headlines on the site: heavy condensed caps (Impact style).
**References (grammar only):** code rain columns, a central light shaft, a wet reflective floor, tall dark
towers with glowing edges and circuit traces (green, which matches the brand: lime and cream code on forest-black). Not taken: the
"WAKE UP" / "MATRIX" signs, the trench-coat figure, katakana glyphs, and any film names or logos.
**Pipeline:** Blender Cycles (skill: blender-farm-render). Built procedurally by
scripts/blender/philips_ident.py, previews here, one packed farm-ready .blend for the final render.
