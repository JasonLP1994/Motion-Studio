# Mia's Motion Graphics Kit

Make motion graphics by talking to Claude. The pictures can come from OpenArt or your own files. Claude builds the motion in code with Remotion, so changing a word is one line, not a new generation.

## What's inside
- mia-motion-graphics/SKILL.md: the skill. How Claude works with you: asks first, plans the beats, shows three stills, builds in code, checks its own render. You never call it by name.
- mia-motion-graphics/setup.md: the one-paste setup prompt (also on the kit page).
- mia-motion-graphics/media-tools.md: how Claude gets eyes (video frames) and ears (word-timed transcripts) with Remotion's own tools. No Python, no FFmpeg install.
- templates/: 10 styles. Each has a preview, a short description (look, motion, build notes, pitfalls) and prompt.txt, a fill-in prompt. code-doodle also has working code (Doodle.tsx).
- mia-motion-graphics/USAGE-TERMS.md and usage.csv.

## Start
Don't unzip anything, the setup does it for you. Add the Remotion plugin in Claude Code (Customize, Plugins, search "remotion", Add). Then make a project folder, open it in the Code tab, and paste the setup prompt from mia-motion-graphics/setup.md. It finds this ZIP in your Downloads folder.

## Usage
Personal, commercial and client projects are allowed. Please share the kit page instead of re-uploading or selling the kit. Preview media is for learning only. Full terms in USAGE-TERMS.md.
